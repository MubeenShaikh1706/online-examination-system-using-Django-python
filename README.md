# Online Examination System

A comprehensive web application designed to manage educational examinations online. Built using the **Django** framework, this project provides a secure and user-friendly platform for both educators and students.

### 🚀 Features
* **Teacher Dashboard:** Create, update, and manage exams or questions.
* **Student Portal:** View upcoming tests, take exams, and view instant results.
* **Role-Based Authentication:** Separate workflows and views for students and teachers.
